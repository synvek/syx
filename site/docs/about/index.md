# About SYX

**SYX** (pronounced *sy-ex*, `/saɪˈɛks/`) is a Swift-inspired programming language with a Rust-implemented compiler toolchain.

| | |
|---|---|
| Source files | `.sy` |
| Project manifest | `syx.toml` |
| Toolchain | `syx` CLI (`syx-cli`) |
| License | Apache-2.0 |
