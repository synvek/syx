# 关于 SYX

**SYX**（读作 *sy-ex*，`/saɪˈɛks/`）是一门受 Swift 启发的编程语言，配套由 Rust 实现的编译器工具链。

| | |
|---|---|
| 源文件 | `.sy` |
| 项目清单 | `syx.toml` |
| 工具链 | `syx` CLI（`syx-cli`） |
| 许可证 | Apache-2.0 |
