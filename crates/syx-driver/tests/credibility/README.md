# Credibility contracts (maintainer-only)

This harness tracks internal credibility-ladder / roadmap ADRs and census scripts.

It is **not** part of the public language test surface. Contributors validating SYX
language behavior should use [`../lang`](../lang) instead.

Filenames describe the hinge under test (census, claim, residual-scope, exit);
stage numbers live in `docs/adr` and `plan/`, not in this directory tree.
