# Os

**Implementation status:** cpu/mem/user/hostname/uptime/disk/load/`primaryIpv4` **Implemented** (failures throw `OsError`); this is **not** a full sysinfo replacement.

```syx
import Os

func main() {
    print(Os.cpuCount())
    try {
        print(Os.hostname())
    } catch (e) {
        print("hostname-unavailable")
    }
}
```

Example: [examples/os_info/main.sy](../../examples/os_info/main.sy)

`Os` is separate from `Process`: the former queries machines/users, the latter handles args/env/exec. Several queries throw when a failure-inducing environment variable is injected (see the comments in `packages/os/mod.sy`), so user code should use `try/catch` rather than relying on `-1` or empty-string sentinels.
