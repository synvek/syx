# Os

**实现状态：** cpu/mem/user/hostname/uptime/disk/load/`primaryIpv4` **已实现**（失败抛 `OsError`）；**不是** 完整 sysinfo。

```syx
import Os

func main() {
    print(Os.cpuCount())
    try {
        print(Os.hostname())
    } catch (e) {
        print("hostname-unavailable")
    }
}
```

范例：[examples/os_info/main.sy](../../../examples/os_info/main.sy)

`Os` 与 `Process` 分开：前者是机器/用户查询，后者是 args/env/exec。若干查询在注入失败环境变量时抛错（见 `packages/os/mod.sy` 注释），用户代码应 `try/catch`，不要依赖 `-1` 或空串哨兵。
