Static file serving works

This page is served from tools/sgate/public/index.html by sgate's static-file location (prefix = "/", root = "./public").

Try the routes

  • /health — canned 200 ok (X-Sgate-Handler: health)
  • /version — canned 200 with body
  • /echo — canned 200 from prefix="/echo" location
  • /api/users — proxied to upstream api (with strip_prefix="/api/")
  • /web/ — proxied to upstream web
  • /static/index.html — this same page served from the static_files location
  • /nope — 404 with configured body

Configuration

All routes are defined in tools/sgate/sgate.json and loaded at startup. Edit, restart, repeat.
